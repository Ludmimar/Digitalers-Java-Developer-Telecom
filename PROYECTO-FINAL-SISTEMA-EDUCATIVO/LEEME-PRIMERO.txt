┌───────────────────────────────────────────────────────────────────────────┐
│                      🚀 INICIO RÁPIDO (3 PASOS)                           │
└───────────────────────────────────────────────────────────────────────────┘

  PASO 1: Abrir MySQL Workbench
          → File → Open SQL Script → 01_schema.sql
          → Execute All (⚡)
          → File → Open SQL Script → 02_datos_prueba.sql
          → Execute All (⚡)
          ✅ Base de datos lista!

  PASO 2: Configurar password de MySQL
          → Abrir: backend/.../utilidades/ConexionDB.java
          → Línea 18: Cambiar CLAVE = "tu_password"
          ✅ Conexión configurada!

  PASO 3: Ejecutar backend
          → Abrir terminal en backend/
          → mvn compile
          → mvn exec:java
          ✅ Sistema corriendo!

  BONUS: Abrir frontend
          → Doble click en: frontend/index.html
          ✅ Interfaz web abierta!
