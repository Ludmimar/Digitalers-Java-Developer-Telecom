## 🎯 Objetivo del Curso
Formar desarrolladores **Java Fullstack** y **web**, con habilidades en **backend, frontend, bases de datos, integración de IA y servicios web**, capaces de crear aplicaciones completas y modernas.

## 📚 Cómo Usar Este Repositorio

### Para Estudiantes

#### **Paso 1: Clonar el Repositorio**
```bash
git clone https://github.com/Ludmimar/Digitalers-Java-Developer-Telecom.git
cd Digitalers-Java-Developer-Telecom
```

#### **Paso 2: Explorar los Módulos**
- Cada carpeta `MOD XX/` contiene material específico del módulo
- Revisa el `README.md` de cada módulo para instrucciones detalladas
- Los PDFs en `DOCS/` contienen la teoría

#### **Paso 3: Configurar el Entorno**
**Para MOD 01-05 (Java Básico)**:
- JDK 8 o superior
- IDE: Eclipse o IntelliJ IDEA

**Para MOD 06-09 (Frontend)**:
- VS Code
- Extensiones: Live Server, Prettier

**Para MOD 10-14 (Bases de Datos)**:
- MySQL o MariaDB
- MySQL Workbench

**Para MOD 20-28 (Backend Java EE)**:
- Apache Maven
- Apache Tomcat 9
- MySQL
- Eclipse IDE for Java EE Developers

#### **Paso 4: Ejecutar los Proyectos Finales**

**Proyecto 1 (Consola)**:
```bash
cd PROYECTO-FINAL-SISTEMA-EDUCATIVO/backend
mvn clean install
mvn exec:java
```

**Proyecto 2 (Web)**:
```bash
cd "PROYECTO-FINAL-SISTEMA-EDUCATIVO 01"
# Seguir instrucciones en docs/01-INICIO-RAPIDO.md
```

### Para Reclutadores y Revisores Técnicos
1. **Revisa los proyectos finales** en las carpetas `PROYECTO-FINAL-*`
2. **Consulta la documentación técnica** en cada carpeta `docs/`
3. **Examina el código** organizado por capas (entidades, DAO, servlets, JSP)
4. **Verifica patrones de diseño**: DAO, Singleton, MVC
5. **Comprueba las buenas prácticas**: Separación de responsabilidades, manejo de excepciones

### 🚀 **Opciones de Hosting Gratuito Recomendadas**

#### **1. Railway.app** ⭐ (MÁS RECOMENDADA)
- ✅ Deploy en minutos con soporte nativo para Java/Tomcat
- ✅ MySQL incluido en el plan gratuito
- ✅ $5 USD/mes de crédito gratis
- ✅ Deploy automático desde GitHub
- 📦 **Características**: 500 horas/mes, 1GB RAM, 1GB disco

**Comandos rápidos**:
```bash
npm i -g @railway/cli
railway login
railway init
railway up
```

#### **2. Oracle Cloud Free Tier** (SIEMPRE GRATIS)
- ✅ Recursos ilimitados en el tiempo
- ✅ 2 VMs con 1GB RAM cada una
- ✅ Base de datos MySQL/Oracle gratuita
- ⚙️ Requiere configuración manual (SSH, Tomcat, MySQL)

#### **3. Render.com**
- ✅ Completamente gratuito con limitaciones
- ✅ PostgreSQL gratuito (750 horas/mes)
- ⚠️ Se duerme después de 15 min de inactividad
- ⚠️ MySQL NO incluido (solo PostgreSQL)

#### **4. Fly.io** (Con Docker)
- ✅ 3 VMs gratuitas (256MB RAM cada una)
- ✅ Basado en Docker
- 🐋 Requiere crear `Dockerfile`

### 📋 **Preparación para Deployment**

Para Railway o cualquier plataforma basada en contenedores:

```dockerfile
# Dockerfile en la raíz del proyecto backend
FROM tomcat:9-jdk11
COPY target/*.war /usr/local/tomcat/webapps/ROOT.war
EXPOSE 8080
CMD ["catalina.sh", "run"]
```

**Variables de entorno necesarias**:
```properties
DB_HOST=tu-host-mysql
DB_PORT=3306
DB_NAME=sistema_educativo
DB_USER=tu-usuario
DB_PASSWORD=tu-password
```

**Ver documentación completa de deployment** en:
- `PROYECTO-FINAL-SISTEMA-EDUCATIVO 01/docs/01-INICIO-RAPIDO.md`
