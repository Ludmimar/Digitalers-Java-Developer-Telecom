# Resolución Desafío Módulo 2 (MOD 31)

## Resumen
Solución del desafío con API REST (personas/productos), capas controller/service/repository.

## Requisitos
- JDK 17 (o 11)
- Maven 3.8+

## Ejecución
```bash
mvn spring-boot:run
# o
mvn clean package
java -jar target/demo-*.jar
```

## Endpoints (ejemplos)
- GET /personas
- GET /productos
