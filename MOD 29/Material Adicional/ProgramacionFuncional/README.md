# Programación Funcional (MOD 29)

## Resumen
Ejemplos Maven con estilos Imperativo vs Declarativo y funciones puras.

## Requisitos
- JDK 11+
- Maven 3.6+

## Build y ejecución
```bash
mvn clean package
mvn -q exec:java -Dexec.mainClass="com.educacionIT.javase.principal.Imperativo"
# Alternativas
mvn -q exec:java -Dexec.mainClass="com.educacionIT.javase.principal.Declarativo"
```
