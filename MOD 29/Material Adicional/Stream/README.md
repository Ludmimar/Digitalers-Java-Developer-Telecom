# Streams (MOD 29)

## Resumen
Ejemplos Maven con `map`, `filter` y `reduce` en Java Streams.

## Requisitos
- JDK 11+
- Maven 3.6+

## Build y ejecución
```bash
mvn clean package
mvn -q exec:java -Dexec.mainClass="com.educacionIT.javase.principal.StreamMap"
# Alternativas
mvn -q exec:java -Dexec.mainClass="com.educacionIT.javase.principal.StreamFilter"
mvn -q exec:java -Dexec.mainClass="com.educacionIT.javase.principal.StreamReduce"
```
