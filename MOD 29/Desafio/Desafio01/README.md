# Desafío 01 (MOD 29)

## Resumen
Ejercicio Maven con entidad `Usuario` y clase `Principal` para practicar POO y Streams.

## Requisitos
- JDK 11+
- Maven 3.6+

## Build y ejecución
```bash
mvn clean package
mvn -q exec:java -Dexec.mainClass="com.educacionit.principal.Principal"
```

Ajusta `-Dexec.mainClass` si cambia el paquete/clase `Principal`.
